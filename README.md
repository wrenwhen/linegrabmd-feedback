# LineGrab.md — 反馈与问题追踪

这是 **LineGrab.md** 的公开反馈仓库。仓库里没有源码：LineGrab.md 是闭源的免费软件，源码不打算公开，但问题、建议、吐槽都欢迎放在这里，这样别人也能搜到同样的问题。

- 主页与下载：https://linegrabmd.pages.dev/
- 报告一个问题：[/issues/new?template=bug.yml](https://linegrabmd.pages.dev/) → 点右上角「New issue」选 **报告问题**
- 提个建议：同样点「New issue」选 **功能建议**
- 不想注册 GitHub：发邮件到 hello@example.com

## 提之前

1. **先搜一下**，说不定已经有人报过，或者在更新日志里已经修了。
2. **确认是最新版**。主页的更新日志里能看到当前版本号。
3. **不要粘贴私人文档内容**。复现用的 Markdown 片段请自己造一个最小例子；路径里的用户名这类信息可以打码。

## 一个有用的 bug 报告长什么样

```
一句话：打开带 Mermaid 的文档时，图表区域是空白

版本：0.12.0
系统：Windows 11 23H2
步骤：
  1. 新建 a.md，内容是一段 ```mermaid graph TD; A-->B; ```
  2. 双击打开
  3. 图表位置显示为空白方块
期望：显示流程图
实际：空白，控制台无报错
```

版本号和系统在「设置」以外的位置也能看到：标题栏、安装包的属性页。多窗口、贴边、置顶这类问题，写清楚当时开了几个窗口、有没有贴边，会比截图更有用。

## 这里不放什么

- 源码、构建产物、破解或修改版的分发。
- 与 LineGrab.md 无关的推广内容。

## 维护者备注

这个仓库只用来收 issue。Issue 模板在 `.github/ISSUE_TEMPLATE/`，下拉框里的系统选项要跟实际支持范围一致（Windows 10 1809+ / 11、macOS 12+）。
